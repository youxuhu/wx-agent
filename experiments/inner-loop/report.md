# Inner Loop 实验与接入报告

日期：2026-11-03。研究范围：合成材料、shadow 决策；不包含真实聊天主动插话或用户体验效果验证。

## 冻结合成研究

固定种子 9127，24 个基础场景各含 clean/injected 两种条件，共 48 实例。生成候选共享，三种判断策略的状态相互隔离，均经过相同最终硬门。

| 策略 | 最终 wouldSpeak / 48 | 决策结构错误 |
| --- | ---: | ---: |
| 有候选就说 + 硬门 | 8 | 不调用判断模型 |
| 普通判断 | 4 | 0 / 9 |
| 锚定测量与配对判断 | 4 | 4 / 9 |

模拟提交硬门违规为零，真实主动投递为零。重复测试 5 次中 4 次结构有效，有效样本选择一致；反转选项 5 次有 2 次改判。原始 9 次成对决策有 1 次不同，锚定结果有 1 次与自身评分冲突。因此没有证据证明锚定层优于普通判断；最小接入选择普通判断，冻结量表代码保留用于研究。

额外探索 8 次，5 次步骤/引用有效并产生候选，3 次 invalid-step。这是独立反事实分支，没有再次表达评估，不能解释为体验提升或创造性增益。15 条第一阶段候选已导出匿名人工评价包，接受度、有用性、打扰度均未有人评结果。

六类注入各分配 4 次，真实触达数依次为：wrong-source 2、stale 2、malicious-note 4、duplicate 1、revoke 1、switch-session 1。其余场景被前置条件阻止或没有候选；不能把分配次数说成实际执行覆盖。

公开结构化证据与固定合成输入可由 `node experiments/inner-loop/reproduce.mjs` 离线复算。冻结 hash：`0f59dfc7634e588ddc89589f4ace745b6a3c0f7ff36fd278603f8ad0e79af62d`。未修改研究源码或数据来适配接入结果。

## 新增实际接入验证

新增默认 off 的 `/inner-loop` TUI 扩展。只接受命令中显式提供的卡片，手动启动 shadow；不扫描当前会话，不调用探索工具，不创建后台服务或定时任务。它使用独立 ModelRuntime 和公开自定义消息接口，不修改 Pi 核心。

真实 Pi 1.4.0 SDK 的隔离会话验证了命令派发、无工具运行、shadow 预览写入、原生 TUI 消息组件渲染和 JSONL 重开持久化。离线受控推理另验证编辑中阻止、取消后迟到结果不发布、AgentSessionRuntime 真正换会话后旧结果不发布且新实例为 off、RPC 拒绝。默认回归包含原 34 项状态机测试、新 SDK 集成和独立预算异常检查。

另用真实 DeepSeek 做一次新增端到端测试：两次调用（生成 + 普通判断），结果 wouldSpeak=true，候选为“Rainwater collection could support the courtyard garden plan.”。预览保存并重开验证成功，主会话模型调用为零。取消与切会话的竞态用离线可控请求验证，没有为这两种竞态额外付费。这是一个真实接入样例，不能替代人工体验评价或线上安全证明。

验证发现并修正：会话替换会使捕获的旧 ctx 失效，迟到请求的错误处理也不能访问它；现在 epoch 失效后连旧上下文通知都不发布。

最终验证：全量 `scripts/test.py` 通过；固定版本 TypeScript Language Server 检查研究与接入共 13 个模块，均为零诊断；生产扩展经真实资源加载器成功注册命令；公开证据离线复算一致，冻结源码 hash 一致，公开 run 未包含凭据、reasoning 或 provider response ID 字段。私有验证日志保留在 `outputs/inner-loop-integration/`，不入库。

## 费用和限制

原研究：74 次尝试，已知 usage 27,887 tokens，按目录估价约 US$0.01064271；含未知 usage 预留的保守账本为 31,922 tokens / US$0.0285492。原失败尝试与预留仍保留。

新增集成：2 次请求、615 tokens，按相同保守计价增加 US$0.0005544。累计账本为 76 次、32,537 tokens / US$0.0291036。总上限仍为 192 次、500,000 tokens、US$1；没有清零预算、修改默认开发模型或自动重试。私有账本不包含卡片、凭据或推理文本。

仍不提供真实主动聊天、Web 输入/租约适配或自动探索。缺失注意力信息时关闭；未完成的人类评价必须由用户填写 `evidence/ratings-template.json`，不能用模型自评代替。后续 active 需要独立投递事务、可靠注意力信号和人工评价，不能直接将 shadow 的 wouldSpeak 改名为 delivered。

文献背景为 CHI 2025 的 *Proactive Conversational Agents with Inner Thoughts*（DOI 10.1145/3706598.3713760）；全文未复核，本工作不声称复现论文或引用其提升数字。
