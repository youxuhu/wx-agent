# 独立 TUI 聊天 demo：本轮接入报告

用户最终范围是“独立聊天助手，自己在一个文件夹里玩，并能主动说多条”，只处理 TUI。当前实现位于 `assistants/inner/`，本机运行 `pi-chat`。没有 GUI 改动、桌面打包或定时任务。

## 实现

复用 Pi 1.4.0 公开 SDK 的模型、会话和 InteractiveMode；独立 profile/persona，不加载 coding agent 项目资源。普通聊天开放三个受限文件工具；自主分支采用“选动作 → 执行 → 看实际变化审查 → 继续/分享/休息”的链。步骤数与发言条数不写死，费用、文件容量和未回应文本量有硬上限。

默认启动即有活动起点，不需要先收到用户消息。发言不伪装用户输入，使用 `triggerTurn:false` 的自定义消息，不靠自己的消息递归点火。输入、焦点活动和切会话使旧请求失效。没有新进展后停止，不按时间再次启动。新用户短消息完成普通回复后可启动新活动。

活动文件夹可写文字，运行账本不可由模型工具改写；拒绝越界、软链接、Shell、脚本及控制字符。同一 profile 使用进程锁，避免两个实例同时写同一份会话。

## 验证和实际结果

- 离线文件/循环测试：连续 5 个有效动作、3 条主动消息；改写不算进展，相同内容和重复动作停止；取消后迟到结果不能写文件/发消息。覆盖路径、软链接、配额、读取截断与文件权限。
- 真实 SDK：零用户输入启动，3 条主动消息落盘；不伪造 user/assistant；主动消息后第一次聊天可正常写入；重开保持历史、独立 profile 锁和 Shell 拒绝。
- 真实 PTY：fullscreen 与 regular 两种布局，零输入启动 → 5 动作/3消息 → 正常聊天 → stop → 退出/重开无重复主动消息。此组使用本地可控模型，不产生付费调用。
- 新真实 DeepSeek TUI 检查：12 次探索/审查调用完成 6 个实际受审动作，主动发出 2 条不同消息。到达测试单独设置的 12 次请求额度后停止；这不代表模型自己认定已结束，也不是生产中的步数限制。
- 另 2 次真实独立审查：“隔热和握持稳定”调换词序被判无进展；“只许一种材料、不可拆件，因此排除外加套”被判新增约束。它们是小样例，不是效果统计或人类偏好评分。
- 全量离线入口包含原 34 项研究单测、预算/适配器/聊天/文件循环等检查；固定版本 LSP 检查 23 个实现模块。冻结 48 场景只离线复算，未重跑付费实验，人工评分仍为空。

真实新 TUI 的两个发言是在同一次连续活动中产生，不是两个用户输入各触发一条。原先真实普通聊天单调用与 legacy 自动投递检查保留为历史证据，不作为新动态循环的结果重复计算。

## 失败与修复

本轮动态接入共使用 36 次新请求，均保留累计账本，不洗掉失败费用：

1. 首轮 3 次调用，读到起点后只传摘要，模型重读相同文件并被重复门停止；改为传实际观察。
2. 第二轮 3 次调用，后续审查上下文超出 2048 上界，在发下一请求前停止；精简审查元数据和提示，保留费用上界。
3. 第三轮 5 次调用，连续两步后因只保留一个观察而重读旧文件；改为预算内保留近期多文件观察。
4. 第四轮 11 次调用，5 动作/1消息后演员返回 null（输出未满足完整 JSON）；停止且不重试。提示改为每次一个短动作，避免长提纲耗尽单次输出额度。
5. 最终真实 PTY 12 次循环调用 + 2 次独立审查，6动作/2消息及两个语义例子通过。

真实 TUI 还揭示新会话保存冲突：宿主写入纯主动消息后，Pi 的内部首次刷盘状态未同步，首条用户消息会报 EEXIST。修复是原子保存公开 JSONL 记录后调用公开 `setSessionFile` 重新加载同一文件；SDK 与 PTY 已覆盖“先主动发言，再第一次聊天”，不 patch 核心。

原实验与历史接入累计 83 次；本轮新动态检查 36 次，当前累计 **119 次、50,434 tokens、保守 US$0.04668**。剩余最多 73 次尝试、449,566 tokens、US$0.95332；未知消耗仍按预留保守记账，数字不是供应商账单。私有日志在 `outputs/inner-loop-integration/`，不提交凭据或原始私人聊天。

## 限制

这仍是 demo，尚未证明长期自然聊天质量。第二个模型也会误判推进，创作不能等同真实世界验证；未回应文本上限可能让它只创作不再开口。模型停下后不会定时醒来，恢复需要新交互或重启。终端不提供焦点事件时，切窗检测不可靠。

文件限制防止通常路径越界，未承诺对恶意本机进程并发替换目录提供操作系统级沙箱。调用锁遇强制杀进程可能残留，停止核查；不会自行绕过预算锁。更新源码后重启助手，不能依赖 Pi 对 .mjs 的热重载。
